# @mdlearn/studio

MDlearn Studio, the local web app behind the `mdlearn studio` command.

Most people want the [`mdlearn`](https://www.npmjs.com/package/mdlearn) package or the
[desktop app](https://github.com/teo-clerk/MDlearn/releases/latest) instead. See the
[guide](https://github.com/teo-clerk/MDlearn#readme). MIT licensed.
